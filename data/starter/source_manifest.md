# Source manifest

All data in this dataset is synthetic. It is generated by this repository's code from a fixed random seed. No real company, bank, customer, transaction or market-data source was used, downloaded or copied. The FX rates are a seeded random walk, not market rates.

External sources: none.

Generator command: `python -m src.generate --scale starter --seed 20261022`

Seed 20261022, scale `starter`, config fingerprint `8ce3c99d63b685ca`. Python 3.13.18, numpy 2.5.3, pandas 3.0.5, SQLite 3.53.1.
